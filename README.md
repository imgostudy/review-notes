초등 임용 1차 대비 과목별 정리 노트예요. 무료로, 공부하는 누구나 쓰라고 공개합니다.

## 이용 조건 — CC BY-NC-SA 4.0

- ✅ 개인 공부·스터디에서 자유롭게 보고, 인쇄하고, 나눠도 돼요.
- ✅ 고쳐 써도 돼요. 다만 **출처(이 사이트 주소)를 밝히고**, 고친 것도 **같은 조건**으로 공개해야 해요.
- 🚫 **판매 금지** — 이 자료나 고친 것을 돈 받고 팔거나, 유료 강의·책·유료 카페/등급 자료에 넣을 수 없어요.
  파는 걸 보시면 사이트 「피드백」으로 알려 주세요.

교재·교육과정 문서에서 옮긴 부분의 권리는 원저작자에게 있어요. 이 라이선스는 정리·구성 부분에 대한 것이에요.

## 사본(포크)에 대해

포크해서 보관하는 건 괜찮아요. 다만 원본은 오류 제보를 받아 계속 고쳐지고 있어서,
**최신·정정된 내용은 원본 사이트에만 있어요.**

## 오류 제보

사이트 각 쪽의 「피드백」 버튼이나 처리 현황 페이지를 이용해 주세요.
